# Политика инструментов

Диагност может выбрать только действие из `allowed_actions`, указанное графом для текущей категории. Повторно вызывать уже использованный инструмент нельзя; действует лимит `max_tool_calls`.

| Категория | Разрешённые инструменты |
| --- | --- |
| upload | get_upload_rules, check_file, get_service_status |
| service | get_service_status |
| access | check_course_access |
| login | check_demo_account |
| materials | check_material_status |
| grades | check_grade_status |

Инструменты не имеют оболочки и не меняют реальную платформу. `check_file` читает только сообщённые метаданные, остальные возвращают синтетический статус. Неизвестный или некорректный параметр не даёт права выдумать результат. Создание локальной учебной заявки не означает отправку оператору.
